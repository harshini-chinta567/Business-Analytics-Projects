# Business Analytics Projects

This portfolio brings together three academic projects involving forecasting, data preparation, and predictive modeling.

## Projects

| Project | Business question | Methods and tools | Files |
| --- | --- | --- | --- |
| [Sunoco Gas Demand Forecasting](sunoco-gas-demand-forecasting/) | How can weekly U.S. gasoline demand be forecast for inventory and supply planning? | Excel, seasonal indices, regression, ARIMAX | Two workbooks and a methodology summary |
| [Trinity Admissions Modeling](trinity-admissions-modeling/) | Which admitted students are likely to accept their offers? | Python, pandas, decision trees, random forests | Training preparation, test preparation, and modeling notebooks |
| [Housing Price Prediction](housing-price-prediction/) | How do property characteristics relate to residential sale prices? | Python, pandas, seaborn, linear regression, residual diagnostics | Analysis notebook and housing training data |

## Skills demonstrated

- Cleaning missing values and inconsistent categories.
- Exploring relationships using visualizations and descriptive statistics.
- Engineering variables and comparing predictive models.
- Evaluating classifiers and documenting forecasting limitations.
- Connecting model results to business decisions.

## Getting started

Open each project's README for its files, dependencies, and limitations. These are coursework artifacts rather than production applications. Admissions data is omitted, and notebook outputs are cleared to avoid publishing student records.

The notebooks preserve the original analysis; their results have not been independently reproduced as part of preparing this portfolio. The Sunoco report discloses validation-data contamination, so its forecast errors should not be presented as clean out-of-sample performance.
